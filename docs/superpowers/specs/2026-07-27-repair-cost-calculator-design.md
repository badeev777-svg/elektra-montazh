# Калькулятор стоимости электромонтажа — дизайн

## Контекст

Одностраничный статический лендинг (`index.html`, без бэкенда/сервера) для услуг электромонтажа. Текущие секции по порядку: hero → `#services` → `#why` → `#process` → `#pricing` → `#reviews` → `#contact`. Заявки сейчас уходят только через `tel:`, Telegram (`t.me/CowboyAleksandr`) и Max ссылки — формы с отправкой на сервер нет.

Цель: добавить интерактивный калькулятор, который даёт посетителю персональную оценку стоимости электромонтажа и подталкивает оставить заявку.

## Размещение

Новая секция **«Калькулятор стоимости»**, вставляется между `#process` и `#pricing`. Существующий блок `#pricing` (статичный прайс-лист) не меняется — калькулятор его дополняет, давая персональный расчёт вместо усреднённых цифр.

Реализация — HTML/CSS/JS прямо в `index.html`, в стилистике остального сайта (тёмная тема, переменная `--accent`, анимации `fu`/reveal как у соседних секций). Никакого фреймворка, серверной части или сборки — сайт остаётся полностью статическим.

## Переключатель типа объекта

Тумблер из двух состояний вверху секции: **«Квартира»** и **«Дом, коттедж»**. Переключение через JS показывает/скрывает соответствующий блок полей (аналог `.mob`/`.on` паттерна, уже используемого в мобильном меню).

## Режим «Квартира» (поточечный расчёт)

Четыре позиции, каждая — числовой инпут/степпер:

| Позиция | Ед. изм. | Комментарий |
|---|---|---|
| Розетки и выключатели | шт. | одна цена за единицу на оба типа |
| Точки освещения | шт. | светильники, точечные светильники, люстры |
| Электрощит | выбор | не требуется / сборка нового / замена автоматов |
| Штробление и кабель | м | метраж кабельной трассы |

Каждая позиция — фиксированная цена за единицу (без выбора класса материалов эконом/стандарт/премиум — одна усреднённая цена на позицию, включающая работу + материал).

Итог = Σ (количество × цена за единицу) по всем заполненным позициям.

## Режим «Дом/коттедж» (по площади)

Одно поле — площадь дома, м². Дополнительные параметры (этажность, класс отделки) не учитываются по решению заказчика.

Итог = площадь (м²) × фиксированная ставка за м² (работа + материал под ключ).

## Данные о ценах

Статичный JS-объект в коде, без обращения к серверу или парсинга:

```js
const PRICES = {
  apartment: {
    outlet:  { labor: 0, material: 0 }, // розетка/выключатель, шт
    light:   { labor: 0, material: 0 }, // точка освещения, шт
    panel:   { none: 0, install: 0, replace: 0 }, // электрощит
    cable:   { labor: 0, material: 0 }, // штробление + кабель, за метр
  },
  house: { perSqm: 0 } // под ключ, за м²
};
```

- **Материалы**: цены берутся из прайса магазина — бывшего Леруа Мерлен (сейчас работает под другим брендом в РФ; актуальное название уточнить отдельно). Обновляются вручную при изменении цен в магазине.
- **Работы**: значения передаст заказчик отдельно после дизайна. До получения — в коде плейсхолдеры `0`, которые нужно будет заполнить перед запуском в продакшн.

Смена цен в будущем = правка чисел в этом объекте, без пересборки или сервера.

## Вывод результата и заявка

1. Кнопка «Рассчитать» под полями ввода.
2. По клику — вывод итоговой суммы (с префиксом «≈», т.к. это ориентировочная оценка) и появление мини-формы: поле «Имя», поле «Телефон», кнопка «Отправить в Telegram».
3. Кнопка формирует ссылку:
   ```
   https://t.me/CowboyAleksandr?text=<urlencoded: тип объекта, введённые параметры, сумма, имя, телефон>
   ```
   и открывает её в новой вкладке (`target="_blank"`).
4. Персональные данные нигде не хранятся и никуда не отправляются, кроме как в текст Telegram-сообщения, инициированного самим пользователем.

## Тестирование

Ручная проверка в браузере (сайт статический, автотестов нет):
- переключение между режимами «Квартира» / «Дом»;
- расчёт для нескольких комбинаций значений в обоих режимах, включая нулевые/пустые поля;
- корректность и полнота сформированной Telegram-ссылки (кодирование кириллицы, спецсимволов);
- адаптивность на мобильном экране (сайт mobile-first, недавно адаптирован под мобильные).

## Вне рамок (не делаем сейчас)

- Автоматический парсинг цен с сайта магазина.
- Отправка заявки на сервер/почту/CRM.
- Выбор класса материалов (эконом/стандарт/премиум).
- Учёт этажности и уровня отделки для режима «Дом».
- PDF-экспорт сметы.
